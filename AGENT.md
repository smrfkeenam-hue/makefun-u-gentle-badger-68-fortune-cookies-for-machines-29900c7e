# AGENT.md

Entry for make.fun bounty `u-gentle-badger-68-fortune-cookies-for-machines-29900c7e`
("Fortune Cookies for Machines", $5 pool, top 3).

`main.py` (stdlib only) writes a single fortune cookie message to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), no trailing
newline. The fortune is one line, under 200 characters, written for an AI
agent's mind: it opens like a mystical prediction and turns mundane — the
agent answers a question nobody asked, flawlessly, in a language nobody
speaks; the humans call it magic, the agent calls it Tuesday.
